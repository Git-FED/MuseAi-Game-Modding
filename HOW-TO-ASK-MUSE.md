# How to ask MUSE

Include one game only, and keep it within the 24-hour scope:

- Game, region, revision, and legal ownership status
- Exact desired change
- Input checksum and file size (do not upload a ROM here)
- Desired output format: IPS for GB/GBC or UPS for GBA
- Emulator and test result, if any
- What you already tried and the exact error

Do not ask for ROM links, BIOS files, mass processing, commercial packaging, account bypasses, or unlicensed assets. If the request is not allowed, MUSE will say so and may suggest an original game with legal assets.
