# Start here

1. Confirm that you own or are otherwise authorized to use the source dump.
2. Identify the exact game, region, revision, and checksum.
3. Read [DISCLAIMER.md](DISCLAIMER.md) and [RULES.md](RULES.md).
4. Make a clean backup and work on a copy.
5. Check [SUPPORTED-VERSIONS.md](SUPPORTED-VERSIONS.md).
6. Apply only the matching patch format with a trusted patcher.
7. Test in an emulator and record the result.
8. Keep the clean dump, patched copy, patch file, and notes separate.

For help, use the template in [HOW-TO-ASK-MUSE.md](HOW-TO-ASK-MUSE.md).
