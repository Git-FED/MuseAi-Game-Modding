# Troubleshooting

**Patch refuses to apply:** confirm the exact region/revision and checksum. A similarly named ROM is not necessarily compatible.

**Wrong format:** use IPS for GB/GBC and UPS for GBA. Do not rename an IPS file to UPS or vice versa.

**Emulator crashes or graphics are wrong:** restore the clean copy, reapply only the matching patch, and test without save states or cheats. Record emulator version and settings.

**No patch binary is present:** a changelog is documentation, not a patch. Stop rather than fabricating or applying an unrelated file; restore the verified binary or request it from the legitimate project maintainer.

**Hardware issue:** stop testing on hardware, return to a clean backup, and reproduce in an emulator first.
