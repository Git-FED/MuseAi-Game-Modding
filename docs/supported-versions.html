META-GBA DOCUMENTATION

Supported versions

IPS for GB/GBC. UPS for GBA. The file extension is not a tiny wizard.

Formats

  • GB/GBC: IPS.
  • GBA: UPS.

IPS cannot reliably address a full 16 MiB GBA ROM, so GBA patches are not described as IPS-only.

LeafGreen status

The rotation UPS was missing from the supplied workspace; only its changelog was available. It is not included. The new-colors UPS path is a clearly marked non-functional placeholder until the real binary is restored and checksum-verified.
